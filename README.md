### ❤️ Heart Risk Predictor — Project Highlights

- Developed an end-to-end machine learning web application to predict cardiovascular risk scores from seven patient health features.
- Implemented a Linear Regression baseline and a feedforward neural network using TensorFlow/Keras.
- Built a neural network architecture with 128-64-10-1 units, dropout, Adam optimization, and mean squared error loss.
- Applied Min-Max scaling to input features and target values, selecting the best model checkpoint based on validation loss.
- Achieved an R² score of 0.86 on a 20% validation split and integrated predictions into a Flask web application.
